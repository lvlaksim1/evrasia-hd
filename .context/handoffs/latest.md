# Передача состояния следующему сеансу

Менеджер `evrasia-hd-main-project-manager` отвечает только за `lvlaksim1/evrasia-hd@main`. На 26.10.2026 опубликована **v15**, `evrasia-hd-v15.apk`, проверена сборка и подпись; релиз https://github.com/lvlaksim1/evrasia-hd/releases/tag/v15, сборка https://github.com/lvlaksim1/evrasia-hd/actions/runs/40247536808; SHA-256 `7d9694ab392e414fbfde997e075f48824136317305b66476f303c54d30bb88ae`.

В v15 реализовано обновление приложения: проверка GitHub Releases при запуске, предложение обновления, кнопка в настройках, прогресс, SHA-256, нативный установщик. Встроенное обновление доступно начиная с v15; переход с v14 требует однократной ручной установки v15. Источники: `docs/updates.md`, `App.tsx`, `lib/evrasia-update.ts`, `plugins/with-update-installer.js`.

**Открытая приёмка:** пользователь подтвердил, что v14 работает на телефоне, но ещё не проверил v15. До такой проверки не утверждать, что обновление работает на устройстве. Автоматический переход v15→v16+ также не был испытан.

Очистка веток и отключение Dependabot завершены ранее. Проверочный сценарий сборки удалён после успеха. Не инициировать новый выпуск без поручения; ждать результатов пользовательского испытания и новых задач.
