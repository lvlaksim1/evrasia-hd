# Активные обязательства менеджера

- **active**: вести независимое постоянное состояние менеджера `lvlaksim1/evrasia-hd` и записывать подтверждённые долговременные изменения без ожидания отдельной команды «сохрани контекст»; основание: прямое указание владельца.
- **active**: сохранять инварианты приложения, данные учётных записей и действующую трёхуровневую систему выпуска; основание: основные документы продукта.
- **active**: перед существенными действиями сверять живую ветку `main`, код и результаты сборки, а после выполнения проверять и фиксировать подтверждённый результат; основание: контракт менеджера.
- **active**: принимать последующие конкретные поручения владельца, устанавливать границы полномочий, выполнять проверяемые изменения и сохранять решения; основание: прямая договорённость о постоянном ведении проекта.
