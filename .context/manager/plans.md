# Текущие планы

1. Проверить целостность впервые созданного поколения капсулы и его принадлежность основному проекту.
2. При получении нового запроса владельца определить затрагиваемые части приложения и проверяемый результат.
3. Реализовывать минимальные изменения на основе живого `main`, учитывая выпускные инварианты и ограничения владельца.
4. Проверять изменения по исходникам, доступным проверкам и отдельной пользовательской приёмке, не объявлять успех без оснований.
5. После существенных подтверждённых выводов сохранять BDI-состояние, память и связанный маркер целостности атомарно.
