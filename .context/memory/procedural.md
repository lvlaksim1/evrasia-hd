# Процедурная память

- Перед изменением приложения проверять head `main`, затронутые исходные файлы, требования и воспроизводимые критерии проверки; source: `ARCHITECTURE.md`, `RELEASE.md`, контракт менеджера; authority: verified-repository.
- Использовать маркер `[release]` только для отдельно разрешённого выпуска и соблюдать трёхуровневую схему; source: `RELEASE.md`, `.github/workflows/android-apk.yml`; authority: verified-repository.
- При изменении долговременного состояния пересчитывать `git-blob-sha1` восьми связанных файлов и публиковать новые значения одним согласованным поколением; source: закреплённый контракт `context-capsule-project-manager`; authority: verified-repository.
- Штатно проверять `pmctl validate`, `ready`, `recover` в GitHub Actions `.github/workflows/validate-project-manager.yml`; сценарий получает Project Manager из точного commit, указанного в `.context/capsule.json`, и проверяет authoritative `main`; source: https://github.com/lvlaksim1/evrasia-hd/actions/runs/40237537909 и исходный сценарий; authority: verified-ci.
- Браузерные запросы `evrasia.rest` используют изолированные cookies каждого аккаунта в SecureStore. История и PIN **не должны запускать скрытый логин и 2FA**; при подтверждённом истечении сначала допускается одна проверяемая попытка восстановления через `public_session.php`, и только при невозможности восстановления требуется ручной вход. Для PIN использовать только выбранный в настройках API; в браузерном режиме не ожидать SMS и не отправлять PIN-запрос повторно. Source: `docs/browser-otp-login.md`, `App.tsx`, `lib/evrasia-api.ts`; authority: owner-directive + verified-repository.
- При запросе истории/карт/браузерного PIN проверять сохранённую сессию; при явном истечении можно один раз запросить `public_session.php` с актуальными параметрами HTML страницы, но без старого PHPSESSID. После `SESSION_CHANGED` обязательно проверить `/account/`. Ответ `SESSION_EXPIRED` — ручной вход; сетевой сбой — не удалять cookies. Никогда не повторять автоматически PIN-запрос или не записывать секреты в журнал; source: `docs/browser-otp-login.md` и исследование владельца 26.10.2026; authority: owner-provided-evidence + verified-repository.
