# Открытые вопросы и риски

**Блокирующих проблем сборки или публикации нет:** v18 опубликована, последние проверки GitHub Actions успешны. Открытые вопросы относятся к *приёмке реального серверного поведения*, а не к готовности APK.

1. **v18 не подтверждена на телефоне.** Проверить, что после обновления работают вход с 2FA, история, карты, запрос PIN мобильным и браузерным API, настройки и сохранение аккаунтов.
2. **Восстановление PHP-сессии не испытано на устройстве:** действующая сессия без лишних запросов; отсутствие только `PHPSESSID`; восстановление после простоя/перезапуска; применение нового `PHPSESSID`.
3. **Неизвестные ограничения Bitrix:** срок действия `k`, минимально достаточные cookies, отзыв долговременной авторизации, обработка `SESSION_EXPIRED` и неуспешной проверки `/account/`. Нет гарантии восстановления при любом истечении.
4. **Отрицательные случаи:** сетевая ошибка и HTTP 5xx не должны очищать авторизацию; один аккаунт не влияет на другой; повтор PIN-запроса запрещён; журнал не должен содержать cookie, CSRF, `k` и PIN.

Последний подтверждённый владельцем рабочий набор функций — v17; выпуск v18 подтверждён GitHub CI, но не устройством.
