# Открытые вопросы приёмки

- **v17 не проверена на реальном Android-устройстве**. Необходимо подтвердить работу отдельного нативного модуля cookies, корректную отправку Bitrix логина и TOTP, сохранение состояния после перезапуска и отделение сессий разных аккаунтов.
- История и карты должны пользоваться уже открытой браузерной сессией. При истечении требуется явный повторный вход, без скрытого запроса TOTP при просмотре истории.
- Новый браузерный PIN должен приходить напрямую из `pincode.php`, без SMS; проверить правильность четырёхзначного кода и формат копирования в буфер. Мобильный SMS-способ должен остаться рабочим.
- Переключатель метода кода списания должен сохранять выбранное значение при перезапуске.
