# Открытые риски и вопросы

- **Приёмка v15 на Android-устройстве не проведена.** До сообщения владельца считать подтверждёнными лишь успешную сборку и проверку APK, но не работу нативного системного установщика и сохранение пользовательского состояния на реальном телефоне.
- **Автоматическое обновление v15 → v16+ не испытано**, поскольку более нового опубликованного релиза нет. Не выпускать тестовый v16 без поручения владельца.
- Android требует подтверждение установки и может потребовать разрешить установку из источника; полностью бесшумная установка не предусмотрена системой.

Устранено: несоответствия старой документации, устаревший пакет `tools` при настройке Android SDK, дополнительные ветки и Dependabot. GitHub CI для v15 успешен: https://github.com/lvlaksim1/evrasia-hd/actions/runs/40247536808.
