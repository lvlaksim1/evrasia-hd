# Следующие действия

1. Получить следующее поручение владельца по развитию приложения, сохранив подтверждённую исправность v14.
2. Не восстанавливать удалённые экспериментальные ветки и не переносить их содержимое в `main` без новой прямой команды.
3. При появлении новых Dependabot-запросов оценивать их отдельно; автоматическое обновление инфраструктуры не равно разрешению на выпуск APK.
4. После следующих содержательных изменений сохранять и штатно проверять согласованную капсулу менеджера.
