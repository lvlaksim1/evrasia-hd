# Следующие действия (приоритет)

1. Провести приёмку **v18** на телефоне после обновления с v17: сохранение учётных записей и настроек, 2FA при обычном входе, работа истории/карт, получение PIN браузерным и мобильным API.
2. При доступном воспроизводимом сценарии проверить восстановление PHP-сессии: отсутствие старого `PHPSESSID` при сохранённых долговременных cookies, серверный `SESSION_CHANGED`, последующее успешное `/account/` без нового кода 2FA. Отдельно проверить простой/перезапуск.
3. Проверить `SESSION_EXPIRED` и недоступность сервера без потери сохранённой авторизации при сетевой ошибке, независимость аккаунтов и отсутствие двойного запроса PIN.
4. После результатов испытания актуализировать доказанные факты и риски в капсуле. Не создавать новых версий/веток для одной лишь проверки без прямой задачи владельца.
