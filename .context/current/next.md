# Следующие действия

1. Получить результаты приёмки **v15** от владельца: установка поверх v14, сохранение аккаунтов, корректный запуск, кнопка «Проверить обновления» в настройках, сообщение об актуальности v15.
2. При следующем реальном выпуске проверить сценарий обнаружения новой версии при запуске, скачивания с проверкой контрольной суммы и перехода в системный установщик, затем зафиксировать результаты.
3. Не создавать экспериментальные ветки, дополнительные релизы или автоматические обновления зависимостей без задачи; поддерживать подтверждённую ранее функциональность.
4. После приёмки обновить долговременную память менеджера и контрольные суммы связанного состояния.
