# Ограничения проекта

- Android package: `com.evrasia.hd`, минимальная версия Android API 24; производственные APK — только arm64-v8a.
- Релизы нумеруются `vN` с `versionCode=N` и `versionName=vN`. Публикация запускается только при сообщении коммита с `[release]`.
- Проектные проверки сохраняются в L3, производственная подпись выполняется только L2, публикация и контроль — L1.
- Не записывать пароли, токены, ключи подписи и личные данные в Git и капсулу.
- Выпуски APK, внешние сообщения, необратимое удаление данных/истории, изменение пакета и разрешений требуют явного указания владельца.
- При любых исправлениях сохранять совместимость, данные и подтверждённое поведение приложения; проверять результат перед заявлением об успехе.
