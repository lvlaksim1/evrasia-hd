# Цели проекта

- Поддерживать Android-приложение «Евразия HD» для работы с несколькими учётными записями, бонусными данными, картами и операциями сервиса.
- Исправлять подтверждённые дефекты без потери существующих функций, пользовательского состояния и стабильности авторизации.
- Сохранять воспроизводимую сборку APK, подпись и проверяемый процесс выпуска.
- Продолжать разработку и приёмку в основном репозитории; сохранять подтверждённые решения и задачи в постоянной памяти собственного менеджера.
