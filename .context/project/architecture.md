# Архитектура основного приложения

- `index.js` регистрирует главный компонент `App.tsx`; в `App.tsx` размещён интерфейс, работа с аккаунтами, сортировка карточек и экраны приложения.
- `lib/evrasia-api.ts`: сетевые запросы, вход, обновление токенов, профиль, карты, история и бонусные операции.
- `lib/evrasia-storage.ts`: данные через AsyncStorage, секреты учётных записей через Expo SecureStore.
- `data/evrasia-seed.ts`: исходные данные ресторанов.
- `app.config.ts` и `plugins/with-sms-code.js`: параметры сборки и собственные возможности Android.
- Производственная сборка: L3 (проектная подготовка неподписанного APK) → L2 (проверки и подпись) → L1 (публикация и проверка результата). Источники: `ARCHITECTURE.md` и `RELEASE.md`.

В `README.md` и `ARCHITECTURE.md` встречается прежний путь `app/(tabs)/index.tsx`, отсутствующий в текущем дереве. При изменениях исходного кода использовать фактическую структуру `index.js` → `App.tsx`.
