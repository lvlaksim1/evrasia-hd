# Проверка и установка обновлений

Начиная с v15 приложение «Евразия HD» проверяет `https://api.github.com/repos/lvlaksim1/evrasia-hd/releases/latest` после загрузки пользовательского интерфейса. Проверка выполняется асинхронно, не требует авторизации GitHub и не блокирует работу приложения.

## Поведение

- На запуске при наличии более новой опубликованной стабильной версии показывается выбор «Позже» / «Обновить».
- В настройках «Проверить обновления»: если более новая версия есть, загрузка начинается немедленно; если нет, выводится уведомление.
- Ошибки фоновой проверки записываются в журнал действий; ошибки проверки по кнопке выводятся пользователю.
- При загрузке показывается процент. Отмена на этой стадии не поддерживается.
- После успешной проверки файла приложение открывает стандартный экран установки Android. На Android 8+ устройство может попросить дать приложению разрешение «Установка неизвестных приложений». Самостоятельной бесшумной установки нет.

## Источник, проверка и ограничения

- Принимаются только стабильные `vN`, `N > versionCode` установленного приложения.
- Установочный файл должен называться `evrasia-hd-vN.apk` и находиться в публичном GitHub Release этого репозитория.
- `assets[].digest` должен содержать SHA-256. Отсутствие контрольной суммы блокирует установку.
- Kotlin-модуль скачивает APK только по HTTPS с GitHub, проверяет полный размер, SHA-256, имя Android-пакета `com.evrasia.hd` и ожидаемый `versionCode`.
- Android дополнительно проверяет совместимость подписи при установке поверх существующего приложения; прежние пользовательские данные остаются на месте при штатной установке.
- APK загружается в закрытый временный каталог приложения и передаётся установщику через Android FileProvider.
- Обновление со старой v14 на v15 требует **однократной ручной установки** v15, так как в v14 этот механизм отсутствует. Начиная с v15 дальнейшие обновления доступны через приложение.

## Исходные файлы

- `lib/evrasia-update.ts` — запрос сведений о выпуске и проверка его метаданных.
- `App.tsx` — уведомление при запуске, кнопка в настройках, прогресс и ошибки.
- `plugins/with-update-installer.js` — системное разрешение, FileProvider, Kotlin-модуль загрузки и запуска установки.
- `plugins/with-sms-code.js` — регистрация Kotlin-модуля в существующем наборе нативных модулей.
