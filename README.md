# Евразия HD

Чистый репозиторий приложения «Евразия HD».

## Версия 1

Версия 1 является функциональной копией Евразия HD v45 из предыдущего репозитория, перенесённой без истории старых версий, резервных копий и архивов.

## Релизы

Номер нового релиза определяется автоматически по последнему тегу `vN`.

- первый релиз: `v1`;
- следующий: `v2`, затем `v3` и т. д.;
- обычный commit не создаёт релиз;
- commit с маркером `[release]` запускает сборку и публикацию следующего релиза;
- workflow можно запустить вручную через `workflow_dispatch`.
